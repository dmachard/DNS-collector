# Deployment Configurations

DNS-collector can be deployed in different configurations depending on your infrastructure size, security requirements, and network topology. 

Select a deployment architecture below to view detailed setups:

* [Edge Deployment](./edge.md) — Deploy collectors as close as possible to the DNS servers on dedicated nodes in the same local network.
* [Centralized Deployment](./centralized.md) — Stream DNStap logs from multiple remote DNS servers to a single, centralized DNS-collector instance.
